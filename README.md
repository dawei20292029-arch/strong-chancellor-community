# 最强丞相社区版 V1.0

一个面向实战决策、知识治理和多 Agent 协同的 Codex Skill。它不会只顺着用户说，而是先质疑关键假设，再用系统思维与控制方法给出最小行动、指标、反馈时间和停止条件。

## 能解决什么

1. **实战项目与业务决策**：把模糊想法变成可验证目标，识别最脆弱假设，设计低成本实验。
2. **知识库与复杂流程治理**：定位入口过载、出口堵塞、反馈断裂、延迟和局部优化。
3. **多 Agent 协同**：明确集中与自治边界、接口、权限、故障回退和升级条件。

## 快速使用

先下载 [V1.0 安装包](https://github.com/dawei20292029-arch/strong-chancellor-community/releases/tag/v1.0.0)，按 [安装说明](INSTALL.md) 操作。首次使用需要电脑和支持本地 Skills 的 Codex；手机可查看介绍、获取链接。

安装后直接说：

```text
启动最强丞相社区版。请审查我的方案，先质疑关键假设，再给系统诊断、最小行动、指标和停止条件。
```

也可以在提示词中显式使用：

```text
$strong-chancellor-community
```

更多示例见 [示例调用](references/example-prompts.md)。

## 输出方式

默认只给三个区块：

- 结论与质疑；
- 工程/系统检查；
- 最小行动、指标和停止条件。

六个后台协议只按问题调用，不要求使用者学习复杂表单。

## 版本边界

### V1.0 已包含的规则

- 主动质疑关键假设；
- 六协议诊断与路由；
- 最小行动、指标、反馈时间和停止条件；
- 事实、推断、假设和候选规则分层；
- 高风险与不可逆操作边界。

这些是已写入的行为约束，不等于模型在所有问题上都已验证可靠。[测试记录](tests/test-results.md) 区分文件校验、安装实测和模型行为测试。

### Candidate

- 跨会话自动积累复盘；
- 自动调度外部 Agent 和生产系统；
- 连接业务数据后的实时控制；
- 无人值守地升级知识库规则。

Candidate 能力需要宿主系统、权限、数据和额外测试，本仓库不宣称已经提供。

## 不包含什么

- 不包含任何原书 PDF、OCR、章节全文或长段摘录；
- 不包含私人知识库、业务案例、本机路径和内部账本；
- 不替代实时检索、专业顾问、业务数据和具体执行工具；
- 不保证建议天然正确，关键判断仍需现实验证。
