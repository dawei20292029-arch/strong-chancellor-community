# 示例调用

## 业务决策

```text
启动最强丞相社区版。我们准备在两周内上线一个付费训练营，预算和人手有限。请先质疑我的关键假设，再给最小验证方案、主指标和停止条件。
```

## 知识库治理

```text
用最强丞相社区版检查这个知识库流程。现在每天进入大量材料，但检索命中率和复用率没有提高。请判断问题更可能在入口、加工、出口还是反馈，并给本周能执行的动作。
```

## 多 Agent 协同

```text
请以最强丞相社区版审查我的 Agent 分工。总控经常成为瓶颈，执行 Agent 之间也会重复工作。请给出权限边界、接口、升级条件和故障回退方案。
```

## 结果复盘

```text
这是本轮的目标、动作、日志和结果。请区分事实、推断和假设，找出最大偏差，并判断哪些经验能成为候选规则，哪些还需要复测。
```

## 推荐输入

不必填写复杂表单。能提供以下五项时，结论会更可靠：

```text
目标：
现状：
约束：
已有证据：
最担心的失败：
```
